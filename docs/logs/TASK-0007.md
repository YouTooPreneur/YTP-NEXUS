## Notes for next task
- `pnpm verify` is now established as the central verification tool for all subsequent cards.
- It executes four initial steps in order:
  1. `API client` (`pnpm api:generate`)
  2. `Type check` (`tsc -p tsconfig.verify.json --noEmit` across packages in `apps/` and `packages/`)
  3. `Set-up tests` (`node --test` for selected `tests/setup/*.test.mjs`)
  4. `Unit and API tests` (`vitest run` per package for selected unit/API test files)
- With `--card TASK-XXXX`, it adds that card's tests; uncompleted cards in `docs/tasks/INDEX.md` remain excluded from running and type checking.
- `--list` prints step names in order and exits 0.
- `tools/verify/lib.mjs` exports `readLock`, `readIndexStatuses`, `listTestFiles`, `selectTests`, and `packageOf`.
- `tools/verify/steps.mjs` exports `steps`. TASK-0008 will add `Lint`, `Format`, and `Architecture` steps to this array.
- `tsconfig.verify.json` files generated dynamically during type-checking are ignored by git in `.gitignore`.
