A language's switch unlocks only when its native-speaker check is marked done. Until then nobody can pick it, and clients who prefer it get English.

How a new language is added

1. Download the English fileEvery word on every screen, in one spreadsheet
2. Translate itAI can draft it; a native speaker checks it
3. Upload it hereNexus shows any missing words. After the native speaker's check, switch it on. No developer needed.
