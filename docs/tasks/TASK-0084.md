# TASK-0084 · Same-site check for data-changing requests

**Chain:** DATABASE (step 7 of 16) · **Release:** 1 · **Module:** Core · **Part:** Backend (D-187; a shared backend card with no door, AGENTS.md section 7) · **Depends on:** TASK-0016 · **Lane:** careful (security)

**Builder:** Claude, in its own building session (D-185, D-200) · **Reviewer:** a separate Claude checking session (D-200, `docs/templates/CHECK-PROMPT.md`)

**Goal:** the seventh card of step 2.2. Another website must never be able to make a signed-in person's browser change data in Nexus (cross-site request forgery). A new app-level step, the **same-site check**, runs directly after the request ID and logging and before the body is read. It lets every reading request (GET, HEAD, OPTIONS) through. A request that changes data (POST, PUT, PATCH or DELETE) passes only when it comes from Nexus's own address: the browser says where a request comes from in the `Sec-Fetch-Site` header (`same-origin`, or `none` for a request the person started themselves, passes; anything else is refused); a browser that does not send that header sends `Origin`, which must equal Nexus's own address taken from the setting `APP_URL` (read at each request; when `APP_URL` is missing or not an address, every `Origin` is refused). A request with neither header comes from no browser (a script, a test or a server), so it cannot carry someone's sign-in cookie by mistake, and it passes. A refused request gets **403** with the code `not_same_site` and the message `This request did not come from Nexus`, before its body is read and before any door runs, for every path.

## STEPS
1. Create `apps/api/src/shared/same-site.ts` with exactly this content:
   ```ts
   import type { RequestHandler } from 'express';
   import { AppError } from './errors.js';

   // The same-site check (TASK-0084, TECH-DESIGN section 2 step 1 and section 7): a request that changes data
   // (POST, PUT, PATCH or DELETE) must come from Nexus's own address, for every door. The browser says where a
   // request comes from in Sec-Fetch-Site; a browser that does not send it sends Origin, compared with APP_URL.
   // A request with neither comes from no browser (a script or a test), so it cannot carry someone's sign-in
   // cookie to Nexus without them knowing.
   const CHANGING = new Set(['POST', 'PUT', 'PATCH', 'DELETE']);

   // Nexus's own address as a browser writes it in Origin, or undefined when APP_URL is missing or not an address.
   export function ownOrigin(appUrl: string | undefined): string | undefined {
     if (!appUrl) {
       return undefined;
     }
     try {
       const origin = new URL(appUrl).origin;
       return origin === 'null' ? undefined : origin;
     } catch {
       return undefined;
     }
   }

   export function sameSiteCheck(): RequestHandler {
     return (req, _res, next) => {
       if (!CHANGING.has(req.method)) {
         next();
         return;
       }
       const site = req.headers['sec-fetch-site'];
       const origin = req.headers.origin;
       const allowed =
         site !== undefined
           ? site === 'same-origin' || site === 'none'
           : origin === undefined || origin === ownOrigin(process.env.APP_URL);
       if (allowed) {
         next();
         return;
       }
       next(new AppError(403, 'not_same_site', 'This request did not come from Nexus'));
     };
   }
   ```
