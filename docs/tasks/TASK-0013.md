## STEPS
1. Edit the root `package.json`: add `devDependencies` `"@playwright/test": "1.64.1"` (exact) and `scripts` `"e2e": "playwright test"`. Run `pnpm install`, then `pnpm exec playwright install chromium`.
2. Create `playwright.config.ts` at the root (`defineConfig` from `@playwright/test`):
   - `testDir: 'tests/e2e'`, `reporter: [['list']]`, `retries: process.env.CI ? 1 : 0`, `forbidOnly: !!process.env.CI`;
   - `use: { baseURL: 'http://localhost:5173', trace: 'retain-on-failure' }`;
   - two projects: `{ name: 'computer', use: { browserName: 'chromium', viewport: { width: 1600, height: 1000 } } }` and `{ name: 'phone', use: { browserName: 'chromium', viewport: { width: 375, height: 812 }, isMobile: true, hasTouch: true } }`;
   - `webServer`: two entries, `pnpm --filter @ytp/api dev` waiting for `http://localhost:3000/api/health`, and `pnpm --filter @ytp/web dev` waiting for `http://localhost:5173`; each `reuseExistingServer: false` (a busy port then fails loudly instead of testing someone else's code), `timeout: 60_000`.
3. Create `apps/web/src/ApiStatus.tsx`: a named export `ApiStatus` that calls `useGetHealth()` from `./api/nexus` and shows one `<p>` with `API: checking…` while loading, `API: connected` when the query has succeeded, and `API: not reachable` when it has failed.
4. Edit `apps/web/src/App.tsx`: one module-level `new QueryClient()`; `App` returns `<QueryClientProvider client={queryClient}><main><h1 className="font-title text-2xl font-semibold">YTP Nexus</h1><ApiStatus /></main></QueryClientProvider>` (the title classes use the design's Sora title font; without them Tailwind shows the heading as plain body text).
5. Edit `tools/verify/lib.mjs`: `listTestFiles` also finds `tests/e2e/*.spec.ts`.
6. Edit `tools/verify/steps.mjs`: add `End-to-end smoke` directly before `Allowed files`: it runs `pnpm exec playwright test --grep @smoke` with the selected files under `tests/e2e/`; with none selected, `{ ok: true, note: 'no end-to-end tests to run' }`. `Unit and API tests` keeps leaving out the files under `tests/e2e/` (their `packageOf` is `null`).
7. Create `.github/workflows/verify.yml`: name `verify`; on `push` and `pull_request`; one job `verify` on `ubuntu-24.04` with these steps in order: `actions/checkout@v7.0.1`; `pnpm/action-setup@v6.1.0` with `version: 11.10.0`; `actions/setup-node@v7.1.0` with `node-version-file: .node-version` and `cache: pnpm`; `run: pnpm install --frozen-lockfile`; `run: pnpm exec playwright install --with-deps chromium`; `run: pnpm verify`.
