## STEPS
1. Create `apps/api/package.json`. Versions are exact (no `^` or `~`):
   ```json
   {
     "name": "@ytp/api",
     "version": "0.1.0",
     "private": true,
     "type": "module",
     "scripts": {
       "dev": "tsx watch src/main.ts",
       "worker": "tsx src/worker.ts",
       "build": "tsc -p tsconfig.build.json",
       "start": "node dist/main.js",
       "typecheck": "tsc -p tsconfig.json --noEmit",
       "test": "vitest run"
     },
     "dependencies": {
       "express": "5.3.0"
     },
     "devDependencies": {
       "@types/express": "5.0.6",
       "@types/node": "24.19.2",
       "@types/supertest": "7.2.1",
       "supertest": "7.3.1",
       "tsx": "4.23.15",
       "typescript": "6.0.3",
       "vitest": "5.0.5"
     }
   }
   ```
2. Create `apps/api/tsconfig.json` (tests are not in `include`: `pnpm verify` type-checks only the tests it runs, TASK-0007):
   ```json
   {
     "extends": "../../tsconfig.base.json",
     "compilerOptions": {
       "module": "NodeNext",
       "moduleResolution": "NodeNext",
       "types": ["node"],
       "noEmit": true
     },
     "include": ["src", "scripts", "vitest.config.ts"]
   }
   ```
3. Create `apps/api/tsconfig.build.json`:
   ```json
   {
     "extends": "./tsconfig.json",
     "compilerOptions": { "noEmit": false, "outDir": "dist", "rootDir": "src" },
     "include": ["src"]
   }
   ```
4. Create `apps/api/vitest.config.ts`:
   ```ts
   import { defineConfig } from 'vitest/config';

   export default defineConfig({
     test: { environment: 'node', include: ['test/**/*.test.ts'] },
   });
   ```
5. Create `apps/api/src/app.ts`. It exports `createApp(): Express` (type `Express` imported from `express`). The app answers `GET /api/health` with status 200 and the JSON body `{ "ok": true, "service": "api" }`. Nothing else.
6. Create `apps/api/src/main.ts`: reads the port from `process.env.PORT` (default `3000`), calls `createApp().listen(port)`, and prints `api listening on <port>` once listening.
7. Create `apps/api/src/worker.ts`: prints `worker started`, keeps the process running (a timer every 60 seconds that does nothing), and exits with code 0 on `SIGTERM` and `SIGINT`.
8. Run `pnpm install` at the root.
