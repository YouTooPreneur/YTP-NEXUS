5. Create `packages/ui/src/Button.tsx`: a named export `Button` and the types `ButtonVariant = 'primary' | 'secondary' | 'ghost'` and `ButtonProps` (all `<button>` attributes plus `variant?: ButtonVariant`).
   - Default `variant` is `'primary'`; default `type` is `'button'`.
   - It renders one `<button>` with `data-variant={variant}` and the class names joined with single spaces: always `inline-flex min-h-11 items-center justify-center gap-2 rounded-[var(--radius-sm)] px-4 py-2 font-semibold`, then for `primary` `bg-[var(--primary-bg)] text-[var(--primary-ink)]`, for `secondary` `border border-[var(--line)] bg-[var(--card)] text-[var(--ink)]`, for `ghost` `bg-transparent text-[var(--ink)]`, then any `className` passed in.
   - Every other attribute (for example `onClick`, `disabled`, `aria-label`) is passed to the `<button>`.
6. Create `packages/ui/src/index.ts`: `export { Button } from './Button';` and `export type { ButtonProps, ButtonVariant } from './Button';`
