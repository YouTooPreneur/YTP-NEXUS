## STEPS
1. Create `infra/compose.dev.yaml` with the project name `ytp-nexus-dev` and exactly three services:
   - `postgres`: image `postgres:16.15-alpine`; environment `POSTGRES_USER: postgres`, `POSTGRES_PASSWORD: ${POSTGRES_SUPERUSER_PASSWORD}`, `POSTGRES_DB: postgres`; port `5432:5432`; volume `pgdata:/var/lib/postgresql/data`; the folder `./postgres/init` mounted read-only at `/docker-entrypoint-initdb.d`; a healthcheck running `pg_isready -U postgres` every 5 seconds.
   - `seaweedfs`: image `chrislusf/seaweedfs:4.51`; command `server -s3 -dir=/data`; port `8333:8333` (the S3 door); volume `seaweed:/data`.
   - `mailpit`: image `axllent/mailpit:v1.33.0`; ports `1025:1025` (SMTP) and `8025:8025` (web page and API).
   - Named volumes `pgdata` and `seaweed`.
   - No image may use the tag `latest`.
2. Create `infra/postgres/init/00-databases.sql`:
   ```sql
   -- Runs once, when the development database volume is first created.
   CREATE DATABASE nexus_dev;
   CREATE DATABASE nexus_test;
   ```
3. Create `infra/.env.example`. One `NAME=value` per line, in this order, with these made-up values (a line starting with `#` is a comment):
   ```
   # Copy to infra/.env and change every value. Never commit infra/.env.
   POSTGRES_SUPERUSER_PASSWORD=change-me
   DATABASE_URL_APP=postgres://nexus_app:change-me@localhost:5432/nexus_dev
   DATABASE_URL_OWNER=postgres://nexus_owner:change-me@localhost:5432/nexus_dev
   DATABASE_URL_BACKUP=postgres://nexus_backup:change-me@localhost:5432/nexus_dev
   APP_URL=http://localhost:5173
   BETTER_AUTH_SECRET=change-me-to-a-long-random-string
   GOOGLE_CLIENT_ID=change-me
   GOOGLE_CLIENT_SECRET=change-me
   NEXUS_MASTER_KEY=change-me-to-a-long-random-string
   GMAIL_USER=change-me@example.com
   GMAIL_APP_PASSWORD=change-me
   SMTP_URL=smtp://localhost:1025
   FILES_S3_ENDPOINT=http://localhost:8333
   FILES_S3_BUCKET=nexus-files
   FILES_S3_KEY=change-me
   FILES_S3_SECRET=change-me
   BACKUP_S3_ENDPOINT=change-me
   BACKUP_S3_BUCKET=nexus-backups
   BACKUP_S3_KEY=change-me
   BACKUP_S3_SECRET=change-me
   BACKUP_ENCRYPTION_KEY=change-me
   FILES_BACKUP_S3_KEY=change-me
   FILES_BACKUP_S3_SECRET=change-me
   ADDRESS_LIMITS=signin:20/minute,public:60/minute
   SENTRY_DSN=
   TEST_MODE=on
   ```
4. Create `infra/.env.test.example`: the same names and order as `infra/.env.example`, but every database URL points to `nexus_test` instead of `nexus_dev`, and the first comment line reads `# Settings for the automated tests. Made-up values only.`
   In `.gitignore`, add the line `!.env.test.example` directly below the existing line `!.env.example`, so this file is kept in the repository (the line `.env.*` would otherwise hide it).
5. Edit the root `package.json` `scripts`: add
   - `"services:up": "docker compose -f infra/compose.dev.yaml --env-file infra/.env up -d --wait"`
   - `"services:down": "docker compose -f infra/compose.dev.yaml --env-file infra/.env down"`
6. Copy `infra/.env.example` to `infra/.env` on your computer (it is git-ignored; never commit it), run `pnpm services:up`, and check that the Mailpit page opens at `http://localhost:8025`. Then run `pnpm services:down`.
