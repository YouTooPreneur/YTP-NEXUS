**Goal:** the fifth card of step 2.2 (CR-018). Two locks keep one company's data from another's (TECH-DESIGN 5.1). **Lock 2, the database's row rule:** a procedure, `core.add_company_rules(<table>)`, that every later change making a company table calls once. It checks the table has a `company_id uuid NOT NULL` column, turns on row rules for it, makes them bind even the table's owner, and adds one rule, `company_rows`: a query sees and writes only the rows of the company set for its transaction, and with no company set it sees nothing. Owned by `nexus_owner`; nobody else may run it. **Lock 1, the data helper** (`apps/api/src/db/company.ts`): `withCompany(db, companyId, work)` runs `work` in one transaction whose first statement sets the company (it takes the database itself, made with a schema or without one, and refuses a transaction), and `forCompany(column, companyId)` is the filter every query on a company table adds. A value that is not a company ID is refused before it reaches the database, and the error never repeats it. **Core's module card** gets the rule. The planner's tests try both locks on a throwaway company table and check every company table in the database.

1. Create `apps/api/src/db/company.ts` with exactly this content:
   ```ts
   import { eq, sql } from 'drizzle-orm';
   import type { SQL } from 'drizzle-orm';
   import type { NodePgDatabase } from 'drizzle-orm/node-postgres';
   import { PgTransaction } from 'drizzle-orm/pg-core';
   import type { PgColumn } from 'drizzle-orm/pg-core';

   // The company context (TECH-DESIGN 5.1). Two locks keep one company's rows from another's: forCompany adds the
   // company to every query on a company table (lock 1), and the database's row rules, put on each company table by
   // core.add_company_rules, bind every query to the company that withCompany sets for the transaction (lock 2).
   // withCompany takes any of the app's Drizzle databases, made with a schema or without one.
   type Schema = Record<string, unknown>;
   export type Database<S extends Schema = Record<string, never>> = NodePgDatabase<S>;
   export type Transaction<S extends Schema = Record<string, never>> = Parameters<
     Parameters<Database<S>['transaction']>[0]
   >[0];

   const COMPANY_ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

   // A value that is not a company ID is refused before it reaches the database: a failed ::uuid cast would repeat
   // the value in its error, and the error must never name it.
   function checkCompanyId(companyId: string): void {
     if (!COMPANY_ID.test(companyId)) throw new Error('the company is not a valid ID');
   }

   // Runs work in one transaction whose first statement sets the company (true: for this transaction only). It takes
   // the database itself, never a transaction: inside one it would only open a savepoint, and the company it set would
   // stay on the outer transaction after the savepoint ends.
   export async function withCompany<T, S extends Schema = Record<string, never>>(
     db: Database<S>,
     companyId: string,
     work: (tx: Transaction<S>) => Promise<T>,
   ): Promise<T> {
     checkCompanyId(companyId);
     if (db instanceof PgTransaction) {
       throw new Error('withCompany needs the database, not a transaction');
     }
     return db.transaction(async (tx) => {
       await tx.execute(sql`SELECT set_config('app.company_id', ${companyId}, true)`);
       return work(tx);
     });
   }

   // Lock 1: the filter every query on a company table adds, for example .where(forCompany(table.companyId, id)).
   export function forCompany(column: PgColumn, companyId: string): SQL {
     checkCompanyId(companyId);
     return eq(column, companyId);
   }
   ```

   ```sql
   -- The company row rule (TECH-DESIGN 5.1): a company table shows and takes only the rows of the company set for
   -- the transaction (app.company_id), for reading and for writing, and binds even the table's owner. Every later
   -- change that makes a company table calls this procedure once, so the rule is written in one place only.
   CREATE PROCEDURE core.add_company_rules(target regclass)
   LANGUAGE plpgsql
   SET search_path = pg_catalog, pg_temp
   AS $$
   BEGIN
     IF NOT EXISTS (
       SELECT FROM pg_attribute
        WHERE attrelid = target AND attname = 'company_id' AND atttypid = 'uuid'::regtype
          AND attnotnull AND NOT attisdropped
     ) THEN
       RAISE EXCEPTION '% has no company_id uuid NOT NULL column', target;
     END IF;
     EXECUTE format('ALTER TABLE %s ENABLE ROW LEVEL SECURITY', target);
     EXECUTE format('ALTER TABLE %s FORCE ROW LEVEL SECURITY', target);
     EXECUTE format(
       'CREATE POLICY company_rows ON %s FOR ALL'
       ' USING (company_id = NULLIF(current_setting(''app.company_id'', true), '''')::uuid)'
       ' WITH CHECK (company_id = NULLIF(current_setting(''app.company_id'', true), '''')::uuid)',
       target
     );
   END
   $$;
   ```
