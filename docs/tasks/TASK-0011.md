**Goal:** `defineRoute` and `mountRoutes`, the one way every API door is written. A door is either public, or declares its permission and feature key; every non-public request passes the shared steps in the order of TECH-DESIGN section 2. The health door moves into the Core module and uses the helper.

## STEPS
1. Edit `apps/api/package.json`: add `dependencies` `"@ytp/contracts": "workspace:*"` and `"zod": "4.6.7"`. Run `pnpm install`.
2. Create `apps/api/src/shared/route.ts` exporting:
   - `type Action = 'view' | 'create' | 'edit' | 'delete' | 'approve' | 'export'` and `interface Permission { module: string; action: Action }`.
   - `interface RouteInfo { req: Request; route: RegisteredRoute }`.
   - `interface RouteHooks` with exactly these members (each async unless marked):
     `session(info)` (step 4), `inTransaction<T>(info, run: () => Promise<T>): Promise<T>` (step 5, wraps everything after it), `idleTimeout(info)` (6), `twoStepGate(info)` (7), `personLimit(info)` (8), `featureSwitch(info)` (9), `permission(info)` (10), `idempotency<T>(info, run: () => Promise<T>): Promise<T>` (12, wraps the handler), and `hideFields(info, answer: unknown): unknown` (14, not async).
   - `defineRoute(def)` where `def` is `{ contract, handler }` plus either `public: true` or both `permission: Permission` and `feature: string`. A non-public route missing either throws `Error('Route <operationId> must declare its permission and feature key, or be public')`. A public route that also has a permission or feature throws `Error('Route <operationId> is public and cannot declare a permission or feature key')`. The handler receives `{ params, query, body }`, already checked against the contract (typed from the contract's Zod schemas), plus the `RouteInfo`, and returns the answer.
   - `RegisteredRoute`: `{ operationId, method, path, module, public, permission?, feature?, contract, handler }` (from the contract and the definition).
   - `mountRoutes(app, routes, hooks?)`: registers each route on Express with the contract's method and path, the path's `{name}` parts turned into `:name`. A non-public route mounted without `hooks` throws `Error('Route <operationId> needs the shared hooks; they come with steps 2.2 to 2.5')` at mount time.
   - Each request of a **non-public** route runs, in this order: `session` → `inTransaction(` `idleTimeout` → `twoStepGate` → `personLimit` → `featureSwitch` → `permission` → **input check** → `idempotency(handler)` → `hideFields` `)` → the answer is sent as JSON with status 200. A **public** route runs only: input check → handler → answer.
   - **Input check** (step 11): parse `req.params` with `contract.params`, `req.query` with `contract.query`, `req.body` with `contract.body`, each only when the contract has it. Any failure throws `new AppError(400, 'invalid_input', 'Please check the form', fields)`, where `fields` maps `<part>.<path joined with dots>` (for example `body.name`, `params.itemId`) to the first message for it.
   - Any error from a hook, the input check or the handler goes to Express's error handler (TASK-0010's format).
   - `routeRegistry`: an array of every route created with `defineRoute`, in creation order (the checks of TASK-0012 read it).
3. Create `apps/api/src/modules/core/routes/health.ts`: `export const healthRoute = defineRoute({ contract: getHealth, public: true, handler: async () => ({ ok: true, service: 'api' }) })`.
4. Create `apps/api/src/routes.ts`: `export const allRoutes = [healthRoute];` Every later card that adds a door adds it here.
5. Edit `apps/api/src/app.ts`: add `hooks?: RouteHooks` to `AppOptions`; remove the inline health door; in its place call `mountRoutes(app, allRoutes, options.hooks)`. Keep the order of everything else.
