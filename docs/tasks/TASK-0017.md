**Goal:** the eighth card of step 2.2. Every change and every automatic action in Nexus will leave one entry in the **activity log**: who did it (a person, or an automation, an API key, MCP, AI or the system, with a label), what (module, record type, record ID and a readable label such as `CL-0042 Kaveri Hospitals`), when, the old and new value of each changed field, the client it belongs to, and the request that did it. This card makes the table `audit.activity_log` (a company table with the company row rule; the app may only **add and read** entries, never change or delete one) and the writer `writeActivity`, which later cards call in the same transaction as their change, so the entry is kept or undone with it. The writer takes the transaction, the company and the request ID from the request context (TASK-0016), never from the entry, and opens no transaction of its own; inside a security write it writes in that write's own transaction. It checks every ID before the database sees it, keeps a value left undefined as `null`, and refuses an entry without who did it. No door shows the log yet (TASK-0059 and TASK-0076).

2. Create the folder `apps/api/src/modules/core/repository/` and in it `activity-log.ts` with exactly this content:
   ```ts
   import { getContext } from '../../../shared/context.js';
   import { activityLog } from '../schema/activity-log.js';

   // The activity-log writer (TASK-0017, CORE-090, TECH-DESIGN section 2 step 13): every save writes its entry in the
   // transaction on the request context, so the entry is kept or undone together with the change. The company and the
   // request ID come from the context, never from the entry, and the writer opens no transaction of its own. Work
   // outside a request (a job, a command, a test) runs inside runWithContext with its own requestId, companyId and tx.
   export type ActorType = 'automation' | 'api' | 'mcp' | 'ai' | 'system';

   export interface Actor {
     type: ActorType;
     label: string;
     userId?: string;
   }

   export interface ActivityEntry {
     module: string;
     recordType: string;
     recordId: string;
     recordLabel: string;
     action: string;
     changes?: Record<string, { old: unknown; new: unknown }>;
     clientId?: string;
     actor?: Actor;
   }

   const ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

   // An ID is checked before it reaches the database, so a wrong value never appears in a database error.
   function checkId(value: string | undefined): void {
     if (value !== undefined && !ID.test(value)) {
       throw new Error('the activity entry holds an ID that is not valid');
     }
   }

   export async function writeActivity(entry: ActivityEntry): Promise<string> {
     const context = getContext();
     if (!context.tx) {
       throw new Error('the activity log needs the transaction');
     }
     if (!context.companyId) {
       throw new Error('the activity log needs the company');
     }
     let who: { actorType: ActorType | 'person'; actorUserId?: string; actorLabel?: string };
     if (entry.actor) {
       who = {
         actorType: entry.actor.type,
         actorUserId: entry.actor.userId,
         actorLabel: entry.actor.label,
       };
     } else if (context.userId) {
       who = { actorType: 'person', actorUserId: context.userId };
     } else {
       throw new Error('the activity log needs who did it');
     }
     checkId(entry.recordId);
     checkId(entry.clientId);
     checkId(who.actorUserId);
     // A value left undefined is kept as null, so the entry still shows that the field changed.
     const changes = JSON.parse(
       JSON.stringify(entry.changes ?? {}, (_key, value: unknown) =>
         value === undefined ? null : value,
       ),
     ) as Record<string, unknown>;
     const [row] = await context.tx
       .insert(activityLog)
       .values({
         companyId: context.companyId,
         ...who,
         module: entry.module,
         recordType: entry.recordType,
         recordId: entry.recordId,
         recordLabel: entry.recordLabel,
         action: entry.action,
         changes,
         clientId: entry.clientId,
         requestId: context.requestId,
       })
       .returning({ id: activityLog.id });
     if (!row) {
       throw new Error('the activity entry was not saved');
     }
     return row.id;
   }
   ```
