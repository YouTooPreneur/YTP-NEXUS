**Builder:** Antigravity · **Reviewer:** Claude (planning session)

**Goal:** two things to put right before the sign-in screen (TASK-0049) is built:
1. Every request under `/api/auth` is counted in the sign-in limit (20 a minute from one address, shared by everyone behind one office address). The screens call `GET /api/auth/get-session` each time Nexus opens, and it guesses no password, so an office opening Nexus at 10 am could use up the sign-in limit and stop people signing in. Count it in the `public` limit instead.
2. The answers of email sign-in and get-session carry the session token in their JSON, where the page's scripts can read it; the cookie already holds it where they cannot. Leave the token out, and the person's two lock fields (`failedSignins`, `lockedUntil`) too.

     function withoutToken(returned: unknown): Record<string, unknown> | undefined {
       if (typeof returned !== 'object' || returned === null || returned instanceof Error) {
         return undefined;
       }
       const answer: Record<string, unknown> = { ...(returned as Record<string, unknown>) };
       delete answer.token;
       if (typeof answer.session === 'object' && answer.session !== null) {
         const session: Record<string, unknown> = { ...(answer.session as Record<string, unknown>) };
         delete session.token;
         answer.session = session;
       }
       return answer;
     }
