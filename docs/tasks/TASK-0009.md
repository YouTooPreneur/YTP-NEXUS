## STEPS
1. Create `tools/verify/checks/test-lock.mjs` (Node built-ins only) exporting:
   - `sha256Of(path)` → the lower-case hex SHA-256 of the file's bytes.
   - `checkTestLock(root, entries)` (entries as returned by `readLock`) → an array of problem strings, empty when all is well: `missing: <path>` when a file does not exist, `changed: <path>` when its fingerprint differs, `listed twice: <path>` when a path appears more than once.
2. Create `tools/verify/checks/allowed-files.mjs` (Node built-ins only) exporting:
   - `readAllowedFiles(cardMarkdown)` → the list of paths or patterns: the first backticked text of the first cell of every row of the first table after the heading `## ALLOWED FILES` (the header and the `---` row are skipped).
   - `readStartPoint(logMarkdown)` → the hash on the line `- Start point (commit): <hash>` (7 to 40 hex characters), or `null`.
   - `matchesPattern(path, pattern)` → `true` when they are equal, or when the pattern's `**` matches any characters including `/` and its `*` matches any characters except `/`.
   - `IGNORED_PATTERNS` = `['history/**', 'share/**', 'tracker.html']`.
   - `builderFiles(card)` → `['docs/logs/<card>.md', 'docs/evidence/<card>/**', 'docs/STATUS.md', 'docs/tasks/INDEX.md']`.
   - `changedFiles(root, startCommit, card)` → sorted, de-duplicated paths (forward slashes). When `card` is given and the card has its own commits after the start point (from `git log --no-merges --format=%H%x09%s <startCommit>..HEAD`, the commits whose subject line starts with `<card>:`), only the files those commits changed, together (for each one `git diff-tree --no-commit-id --name-only -r <commit>`). This keeps the check right when later cards of a batch were built on top, and when a sent-back card gets a fix commit after them (AGENTS.md section 3a). Otherwise (no `card`, or the card is not committed yet): `git diff --name-only <startCommit>` plus `git ls-files --others --exclude-standard`. Run every git command in `root` with an argument list and no shell, starting the arguments with `-c core.quotepath=off` (for example `execFileSync('git', ['-c', 'core.quotepath=off', 'ls-files', '--others', '--exclude-standard'], { cwd: root, encoding: 'utf8' })`): without a shell, Windows cannot eat the `^`, and with that setting a file name with letters such as é comes back as written instead of quoted with escapes.
   - `checkAllowedFiles({ changed, allowed, card })` → the changed paths that match none of `allowed`, `IGNORED_PATTERNS` or `builderFiles(card)`, sorted.
3. Edit `tools/verify/steps.mjs`:
   - Add **`Test lock`** directly before `Set-up tests`: read `tests/LOCK`; any problem fails the step, and the note lists the problems.
   - Add **`Allowed files`** as the last step. Without `--card`: `{ ok: true, note: 'only with --card' }`. With `--card`: read the start point from `docs/logs/<card>.md` with `readStartPoint` (a missing log, or no start point in it, fails with the note `no start point in docs/logs/<card>.md`), list the changed files with `changedFiles(root, <start point>, card)`, read the allowed list with `readAllowedFiles` from `docs/tasks/<card>.md`, and fail with the note `not allowed: <paths, comma-separated>` when `checkAllowedFiles({ changed, allowed, card })` returns any.

4. Edit `tools/verify/verify.mjs` so a crash never hides the result:
   - Run each `step.run(ctx)` inside `try`/`catch`. A thrown error counts as a failed step with the note `crashed: <the error's message>`; the next steps still run, and the last line is `verify: FAILED: …` as usual.
   - If reading `tests/LOCK` or `docs/tasks/INDEX.md`, or selecting the tests, throws before the steps start, print `verify: FAILED: <the error's message>` on standard output (`console.log`, like every other `verify:` line) and exit with code 1 (for example `verify: FAILED: tests/LOCK line 1: not a lock line`).
5. Edit `eslint.config.mjs`: add the line `import { defineConfig } from 'eslint/config';` after the other imports, and replace `export default tseslint.config(` with `export default defineConfig(`. Change nothing else. (Why: `tseslint.config` copied its file list onto typescript-eslint's block meant only for TypeScript files, which switched off `no-undef` for `.mjs` files, so a misspelt name in verify code passed lint. `defineConfig` keeps that block on TypeScript files.)
6. Edit `.dependency-cruiser.cjs`: in the rules `frontend-never-imports-backend` and `frontend-no-server-packages`, change `from` `path` from `'^(apps/web|packages/ui)/'` to `'^(apps/web|packages/(ui|contracts))/'`. Change nothing else. (Why: the screens will use the shared contracts package to check forms, so that package must not reach the backend or server packages either.)
