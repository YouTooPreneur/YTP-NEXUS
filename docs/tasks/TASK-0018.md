**Chain:** DATABASE (step 12 of 17) · **Release:** 1 · **Module:** Core · **Part:** Backend (D-187; a shared backend card with no door, AGENTS.md section 7) · **Depends on:** TASK-0024 · **Lane:** careful (security; it adds database changes, so no other database card is built at the same time, CR-022)

**Builder:** Antigravity (D-201) · **Reviewer:** Claude (planning session)

**Goal:** the twelfth card of step 2.2. Every security event (a sign-in, a failed sign-in, a lock, a two-step change, a permission change, an export, a session end, a setting change and the others DATA-MODEL 3.3 lists) will leave one entry in the **security log**, `audit.security_log`, which nobody can change or delete. Each company has its own **chain**: every entry has the next number in its chain and a fingerprint (SHA-256) of the entry before's fingerprint and its own fields, so any change or gap shows. Events with no known company (for example a failed sign-in for an email nobody has) go into the **system chain**, which the app never sees. Entries are added only through one database function, `audit.add_security_entry`, owned by the system account: it takes the chain's lock until its transaction ends (waiting at most 5 seconds), reads the chain's last entry and adds the next, so two sign-ins at the same moment never fork the chain. A trigger refuses any change or delete, even by the table's owner. The writer `writeSecurity(entry)` adds an entry in the transaction on the request context (inside a security write, that write's own transaction, so the entry stays when the request is refused), with the person, where the request came from (its address and browser, now kept on the request context) and the request's ID; it hides a password, code, key or token in the details, and refuses an unknown event or a wrong ID. `securityWriteWithoutCompany` writes into the system chain. No code writes an event yet: the sign-in, session, two-step, role and export cards do.

   ```ts
   import { sql } from 'drizzle-orm';
   import { getContext } from '../../../shared/context.js';

   // The security-log writer (TASK-0018, CORE-092). It adds an entry through the database function
   // audit.add_security_entry, in the transaction on the request context: the function takes the chain's lock (held
   // until that transaction ends, waiting at most 5 seconds), continues the company's chain (or the system chain when the
   // transaction has no company) and works out the fingerprint. Inside a security write the context holds that write's
   // own transaction, so the entry stays even when the request is refused. Within one request, every security write that
   // writes an entry runs before any entry the request's own transaction writes.
   export type SecurityEvent =
     | 'signin_ok'
     | 'signin_failed'
     | 'account_locked'
     | 'two_step_changed'
     | 'two_step_reset'
     | 'signin_email_changed'
     | 'session_ended'
     | 'permission_changed'
     | 'role_viewed_as'
     | 'export'
     | 'sensitive_field_viewed'
     | 'vault_reference_opened'
     | 'api_call'
     | 'setting_changed'
     | 'data_erased';

   export interface SecurityEntry {
     event: SecurityEvent;
     userId?: string;
     targetUserId?: string;
     recordType?: string;
     recordId?: string;
     details?: Record<string, unknown>;
   }

   const EVENTS = new Set<string>([
     'signin_ok',
     'signin_failed',
     'account_locked',
     'two_step_changed',
     'two_step_reset',
     'signin_email_changed',
     'session_ended',
     'permission_changed',
     'role_viewed_as',
     'export',
     'sensitive_field_viewed',
     'vault_reference_opened',
     'api_call',
     'setting_changed',
     'data_erased',
   ]);
   const ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
   const HIDDEN = '[hidden]';
   const SECRET = /pass(word|code)|secret|token|apikey|privatekey/;

   // A part of the details whose name looks like a secret, or is exactly a code or a key, is never stored.
   function isSecret(name: string): boolean {
     const letters = name.toLowerCase().replace(/[^a-z]/g, '');
     return SECRET.test(letters) || letters === 'code' || letters === 'key' || letters === 'otp';
   }

   function checkId(value: string | undefined): void {
     if (value !== undefined && !ID.test(value)) {
       throw new Error('the security entry holds an ID that is not valid');
     }
   }

   export async function writeSecurity(entry: SecurityEntry): Promise<number> {
     const context = getContext();
     if (!context.tx) {
       throw new Error('the security log needs the transaction');
     }
     if (!EVENTS.has(entry.event)) {
       throw new Error('the security log does not know this event');
     }
     const userId = entry.userId ?? context.userId;
     checkId(userId);
     checkId(entry.targetUserId);
     checkId(entry.recordId);
     const details = JSON.stringify(entry.details ?? {}, (key, value: unknown) =>
       key !== '' && isSecret(key) ? HIDDEN : value === undefined ? null : value,
     );
     const result = await context.tx.execute(
       sql`SELECT audit.add_security_entry(${entry.event}, ${userId ?? null}::uuid, ${entry.targetUserId ?? null}::uuid, ${entry.recordType ?? null}, ${entry.recordId ?? null}::uuid, ${context.ip ?? null}, ${context.userAgent ?? null}, ${details}::jsonb, ${context.requestId}) AS id`,
     );
     const id = result.rows[0]?.id;
     if (id === undefined || id === null) {
       throw new Error('the security entry was not saved');
     }
     return Number(id);
   }
   ```

     if (!context) {
       throw new Error('No request context');

     return context;

4. Replace the whole content of `apps/api/src/db/database.ts` with exactly this (it adds `securityWriteWithoutCompany` before `closePools`; everything else stays as it is):
   ```ts
   import { Pool, type PoolConfig } from 'pg';
   import { drizzle } from 'drizzle-orm/node-postgres';
   import { getContext, runWithContext, type RequestContext } from '../shared/context.js';
   import { withCompany, type Transaction } from './company.js';

   // The app's two connection pools, both signed in as nexus_app (TECH-DESIGN section 2, steps 5 to 8). The request
   // pool holds each request's transaction; the small security pool holds the short security writes, which commit
   // whatever happens to the request. A request never waits for a second connection from its own pool, so the API
   // cannot lock itself when many requests arrive at once (CR-012). Nothing here reads a setting or opens a
   // connection until first use.

   type Settings = Record<string, string | undefined>;

   // An optional pool size (TECH-DESIGN 6.6): a whole number above 0, or the default.
   export function poolSize(value: string | undefined, fallback: number): number {
     const size = Number(value);
     return Number.isInteger(size) && size > 0 ? size : fallback;
   }

   // Both pools wait at most 10 seconds for a free connection, so a full pool answers 500 instead of hanging; the
   // security pool's connections wait at most 5 seconds for a lock.
   export function poolSettings(settings: Settings = process.env): {
     request: PoolConfig;
     security: PoolConfig;
   } {
     const value = settings.DATABASE_URL_APP;
     if (!value) throw new Error('DATABASE_URL_APP is not set');
     if (!URL.canParse(value)) throw new Error('DATABASE_URL_APP is not a database address');
     const app = new URL(value);
     if (app.username !== 'nexus_app') throw new Error('DATABASE_URL_APP must sign in as nexus_app');
     const address: PoolConfig = {
       host: app.hostname,
       port: Number(app.port) || 5432,
       user: app.username,
       password: decodeURIComponent(app.password),
       database: app.pathname.slice(1),
       connectionTimeoutMillis: 10_000,
     };
     return {
       request: { ...address, max: poolSize(settings.DB_POOL_SIZE, 10) },
       security: { ...address, max: poolSize(settings.DB_SECURITY_POOL_SIZE, 3), lock_timeout: 5_000 },
     };
   }

   interface Pools {
     request: Pool;
     security: Pool;
   }

   let pools: Pools | undefined;

   // A connection that breaks is dropped from its pool and replaced on next use. Without these listeners the error
   // would stop the API: the pool's listener covers a connection while it waits in the pool, and each connection's
   // own listener covers it while a request or a security write holds it (its query then fails, so only that
   // request answers 500).
   function makePool(config: PoolConfig): Pool {
     const pool = new Pool(config);
     pool.on('error', () => {});
     pool.on('connect', (client) => client.on('error', () => {}));
     return pool;
   }

   function getPools(): Pools {
     if (!pools) {
       const settings = poolSettings();
       pools = { request: makePool(settings.request), security: makePool(settings.security) };
     }
     return pools;
   }

   // Runs work in one transaction with the company set, on a connection taken here and always given back, even when
   // its BEGIN fails: Drizzle's own transaction on a pool would keep such a connection, and the pool would shrink for
   // good. A broken connection is dropped when it is given back.
   export async function onConnection<T>(
     pool: Pick<Pool, 'connect'>,
     companyId: string,
     work: (tx: Transaction) => Promise<T>,
   ): Promise<T> {
     const client = await pool.connect();
     try {
       return await withCompany(drizzle(client), companyId, work);
     } finally {
       client.release();
     }
   }

   // Step 5: runs the rest of a request in one transaction on the request pool, with the request's company set
   // (TECH-DESIGN 5.1). The transaction is on the request context while it runs, and the repositories read it there.
   export async function inRequestTransaction<T>(run: () => Promise<T>): Promise<T> {
     const context = getContext();
     if (!context.companyId) throw new Error('the request transaction needs the company');
     return onConnection(getPools().request, context.companyId, async (tx) => {
       context.tx = tx;
       try {
         return await run();
       } finally {
         delete context.tx;
       }
     });
   }

   // The request context, or none outside a request (a job, a test).
   function currentContext(): RequestContext | undefined {
     try {
       return getContext();
     } catch {
       return undefined;
     }
   }

   // A short security write (TECH-DESIGN section 2): its own transaction on the security pool, with the company set,
   // committed whatever happens to the request. While it runs, the request context holds this transaction instead of
   // the request's, so code that reads the transaction there writes into the security write; the request's comes back
   // afterwards. Await nothing inside it that needs the request pool.
   export async function securityWrite<T>(
     companyId: string,
     work: (tx: Transaction) => Promise<T>,
   ): Promise<T> {
     const context = currentContext();
     return onConnection(getPools().security, companyId, (tx) =>
       context ? runWithContext({ ...context, companyId, tx }, () => work(tx)) : work(tx),
     );
   }

   // A short security write with no company (TASK-0018): for an entry in the security log's system chain, such as a failed
   // sign-in for an email nobody has. Its own transaction on the security pool, with no company set, committed whatever
   // happens to the request; the connection is always given back.
   export async function securityWriteWithoutCompany<T>(
     work: (tx: Transaction) => Promise<T>,
   ): Promise<T> {
     const context = currentContext();
     const client = await getPools().security.connect();
     try {
       return await drizzle(client).transaction(async (tx) =>
         context ? runWithContext({ ...context, companyId: undefined, tx }, () => work(tx)) : work(tx),
       );
     } finally {
       client.release();
     }
   }

   // Ends both pools (in the tests now, and when the API stops once a later card wires that up); the next use makes
   // them again from the settings.
   export async function closePools(): Promise<void> {
     const open = pools;
     pools = undefined;
     if (open) await Promise.all([open.request.end(), open.security.end()]);
   }
   ```
