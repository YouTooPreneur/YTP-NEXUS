## STEPS
1. Create `package.json` with exactly this content:
   ```json
   {
     "name": "ytp-nexus",
     "private": true,
     "type": "module",
     "packageManager": "pnpm@11.10.0",
     "engines": {
       "node": ">=24 <25"
     },
     "scripts": {}
   }
   ```
2. Create `pnpm-workspace.yaml`:
   ```yaml
   packages:
     - "apps/*"
     - "packages/*"
   allowBuilds:
     esbuild: true
   ```
   (pnpm 11 refuses to install until every package's install script is approved or refused here; esbuild, which later cards use through tsx and Vite, needs its script.)
3. Create `.node-version` containing one line: `24`
4. Create `tsconfig.base.json`:
   ```json
   {
     "compilerOptions": {
       "target": "ES2023",
       "lib": ["ES2023"],
       "strict": true,
       "noUncheckedIndexedAccess": true,
       "noImplicitOverride": true,
       "noFallthroughCasesInSwitch": true,
       "forceConsistentCasingInFileNames": true,
       "verbatimModuleSyntax": true,
       "isolatedModules": true,
       "esModuleInterop": true,
       "resolveJsonModule": true,
       "skipLibCheck": true
     }
   }
   ```
5. Create `.editorconfig`:
   ```ini
   root = true

   [*]
   charset = utf-8
   end_of_line = lf
   indent_style = space
   indent_size = 2
   insert_final_newline = true
   trim_trailing_whitespace = true

   [*.md]
   trim_trailing_whitespace = false
   ```
6. Create `.gitattributes`:
   ```
   * text=auto eol=lf
   *.png binary
   *.jpg binary
   *.jpeg binary
   *.webp binary
   *.gif binary
   *.ico binary
   *.pdf binary
   *.docx binary
   *.xlsx binary
   *.zip binary
   *.gz binary
   *.woff2 binary
   ```
7. In `.gitignore`, add these lines at the end, under a new heading line `# Nexus code: generated and local files` (keep every existing line):
   ```
   apps/web/src/api/
   packages/contracts/openapi.json
   *.tsbuildinfo
   playwright-report/
   test-results/
   ```
8. Run `pnpm install`. It must finish without errors (there are no packages yet) and creates `pnpm-lock.yaml`, which you commit with this card. On this and every later card: if `pnpm install` ever changes `pnpm-workspace.yaml`, STOP and mark the card BLOCKED.
