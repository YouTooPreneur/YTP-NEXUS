Run `pnpm install`.
2. Create `eslint.config.mjs` (flat config):
   - ignored everywhere: `**/node_modules/**`, `**/dist/**`, `apps/web/src/api/**`, `docs/**`, `history/**`, `share/**`, `assets/**`, `tracker.html`, `tools/*` followed by `!tools/verify/` (these two exact patterns, in this order, in the global ignores), `tests/**`, `apps/*/test/**`, `packages/*/test/**` (planner tests are checked by the planner), `**/tsconfig.verify.json`, `.claude/**`;
   - `@eslint/js` recommended and `typescript-eslint` recommended (not the type-checked set) for all `.ts`, `.tsx`, `.mjs` files;
   - `eslint-plugin-react-hooks` recommended rules for `apps/web/**` and `packages/ui/**`: `...reactHooks.configs.flat.recommended` in a block with `files` `apps/web/**` and `packages/ui/**` (the plain `configs.recommended` is the old format and stops ESLint 10);
   - Node globals (from `globals`) for `apps/api/**`, `packages/contracts/**`, `tools/verify/**` and every `*.config.*` file; browser globals for `apps/web/**` and `packages/ui/**`.
3. Create `.prettierrc.json`: `{ "singleQuote": true, "semi": true, "printWidth": 100, "trailingComma": "all", "endOfLine": "lf" }`.
4. Create `.prettierignore` with these lines: `node_modules`, `dist`, `pnpm-lock.yaml`, `apps/web/src/api`, `packages/contracts/openapi.json`, `docs`, `history`, `share`, `assets`, `tracker.html`, `tests`, `apps/*/test`, `packages/*/test`, `**/tsconfig.verify.json`, `*.md`, `*.css`, `*.html`, `*.json`, `*.yaml`, `*.yml`, `/tools/*`, `!/tools/verify`, `infra`, `CLAUDE.md`, `AGENTS.md`, `.claude`. (So Prettier formats only `.ts`, `.tsx`, `.mjs`, `.cjs` and `.js` code; the design tokens, pages, settings and package files keep the exact text earlier cards wrote.)
5. Create `.dependency-cruiser.cjs`. Options: `doNotFollow` `node_modules`; `exclude` `^(apps|packages)/[^/]+/(dist|test)/` (only the apps' and packages' own build and test folders: an import that resolves into `node_modules` must stay visible, or the frontend wall below could not see it); `enhancedResolveOptions` with exactly these three keys: `extensions` `['.ts', '.tsx', '.mjs', '.js', '.json']`, `exportsFields` `['exports']` and `conditionNames` `['import', 'require', 'node', 'default', 'types']` (the last two let it follow `@ytp/ui` and `@ytp/contracts`, which only have `exports`; add no other key: dependency-cruiser 18 rejects unknown keys, and it already maps `.js` imports to `.ts` files itself). `forbidden` rules, all `severity: 'error'`, with **these exact names**:
   - `frontend-never-imports-backend`: from `^(apps/web|packages/ui)/` to `^apps/api/`.
   - `frontend-no-server-packages`: from `^(apps/web|packages/ui)/` to a module whose path matches `^(pg|drizzle-orm|pg-boss|nodemailer|express)(/|$)` or `^better-auth(/(?!client|react)|$)` (a package, or a path inside it, that cannot be resolved) or `node_modules/(pg|drizzle-orm|pg-boss|nodemailer|express)/` or `node_modules/better-auth/(?!dist/client|react)` (Better Auth's React client stays allowed).
   - `module-walls`: from `^apps/api/src/modules/([^/]+)/` to a file in another module that is not that module's `index.ts` (`to.path` `^apps/api/src/modules/[^/]+/`, `to.pathNot` `^apps/api/src/modules/($1)/|^apps/api/src/modules/[^/]+/index\.ts$`).
   - `core-asks-no-module`: from `^apps/api/src/modules/core/` to `^apps/api/src/modules/(?!core/)[^/]+/`.
   - `floor-rules-<module>`, one rule per module, from `^apps/api/src/modules/<module>/` to `^apps/api/src/modules/(<forbidden list>)/`:
     | module | forbidden targets |
     |---|---|
     | `crm` | `team`, `webcare`, `finance`, `contracts`, `projects`, `academy` |
     | `team` | `crm`, `webcare`, `finance`, `contracts`, `projects`, `academy` |
     | `webcare` | `finance`, `contracts`, `projects`, `academy` |
     | `finance` | `webcare`, `contracts`, `projects`, `academy` |
     | `contracts` | `projects`, `academy` |
     | `projects` | `academy` |
     | `academy` | `webcare`, `contracts`, `projects` |
   - `auth-schema-wall`: from any path matching `^apps/api/src/` except `^apps/api/src/(modules/core/(signin|users)/|db/)`, to `^apps/api/src/db/auth-schema\.ts$` (Core's sign-in and users code live in those two folders, TASK-0012 Core card).
   - `no-circular`: `from: {}, to: { circular: true }` (dependency-cruiser 18 needs a `from` on every rule; an empty `from` matches every file. Corrected after the build, CR-008: the builder found it and added it).
6. Edit `tools/verify/steps.mjs`: after `Type check`, add the steps `Lint` (`pnpm lint`), `Format` (`pnpm format:check`) and `Architecture` (`pnpm depcruise`), in that order.
7. Run `pnpm format` once, then `pnpm lint` and fix what it reports in the allowed files (formatting and lint fixes only; never change what code does).
