# TASK-0025 · Removing personal values on request

**Chain:** DATABASE (step 16 of 18) · **Release:** 1 · **Module:** Core · **Part:** Backend (D-187; a shared backend card with no door) · **Depends on:** TASK-0017, TASK-0018 (both Done) · **Lane:** careful (personal data and the activity log) · **Card style:** fast (D-202)
**Requirement IDs covered:** NFR-010 (DPDP: a deletion request can be carried out and logged), DATA-MODEL 3.3 (delete on request), CORE-090
**Builder:** Codex (D-202) · **Reviewer:** Claude (planning session)

**Goal:** when a person asks Nexus to delete their personal data (India's DPDP Act), the Owner's deletion-request action (a later screen) can remove that person's or record's personal values from the **activity log**: in every entry of that record, in the request's company only, the record's label and the old and new values of the named fields become `[removed on request]`; the entry itself, its other fields and its time stay. This runs through one database function, `core.erase_personal_values`, owned by the system account, which is the only way any account may change an activity entry. `erasePersonalValues(...)` calls it in the request's own transaction and then writes one `data_erased` entry in the security log (who asked, the record, how many entries changed and which fields). If the request is undone, nothing is removed and nothing is logged. Stored double-click answers are not changed: they expire within 24 hours.

   ```sql
-- only their changes and record label, and only through core.erase_personal_values, which the app runs from the Owner's
-- deletion-request action. No other account may change an entry.
GRANT SELECT, UPDATE (changes, record_label) ON audit.activity_log TO nexus_system;
--> statement-breakpoint
SET ROLE nexus_system;
--> statement-breakpoint
-- In the transaction's company, every activity entry of one record: its label, and the old and new values of each field
-- named in p_fields (a list of names), become '[removed on request]'. Gives back how many entries changed.
CREATE FUNCTION core.erase_personal_values(p_record_type text, p_record_id uuid, p_fields jsonb) RETURNS integer
LANGUAGE plpgsql SECURITY DEFINER
SET search_path = pg_catalog, pg_temp
AS $$
DECLARE
  company uuid := NULLIF(current_setting('app.company_id', true), '')::uuid;
  removed constant jsonb := '{"old": "[removed on request]", "new": "[removed on request]"}'::jsonb;
  changed integer;
BEGIN
  IF company IS NULL THEN
    RAISE EXCEPTION 'the removal needs the company';
  END IF;
  IF jsonb_typeof(p_fields) IS DISTINCT FROM 'array' THEN
    RAISE EXCEPTION 'the removal needs a list of field names';
  END IF;
  UPDATE audit.activity_log AS entry
     SET record_label = '[removed on request]',
         changes = (SELECT coalesce(jsonb_object_agg(key, CASE WHEN p_fields ? key THEN removed ELSE value END), '{}'::jsonb)
                      FROM jsonb_each(entry.changes))
   WHERE entry.company_id = company AND entry.record_type = p_record_type AND entry.record_id = p_record_id;
  GET DIAGNOSTICS changed = ROW_COUNT;
  RETURN changed;
END
$$;
--> statement-breakpoint
GRANT EXECUTE ON FUNCTION core.erase_personal_values(text, uuid, jsonb) TO nexus_app;
--> statement-breakpoint
RESET ROLE;
   ```

2. Create `apps/api/src/modules/core/repository/erasure.ts` with exactly this content:
   ```ts
import { sql } from 'drizzle-orm';
import { getContext } from '../../../shared/context.js';
import { writeSecurity } from './security-log.js';

// Removing personal values on request (TASK-0025, DPDP, NFR-010). In the request's own transaction, every activity entry
// of one record loses its label and the old and new values of the named fields (core.erase_personal_values), and a
// data_erased entry is written in the security log last. Only the Owner's deletion-request action calls it.
export interface Erasure {
  recordType: string;
  recordId: string;
  fields: string[];
}

const ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export async function erasePersonalValues(erasure: Erasure): Promise<number> {
  const context = getContext();
  if (!context.tx) {
    throw new Error('the removal needs the transaction');
  }
  if (!ID.test(erasure.recordId)) {
    throw new Error('the removal needs a record ID');
  }
  if (
    !erasure.recordType ||
    !erasure.fields.every((field) => typeof field === 'string' && field !== '')
  ) {
    throw new Error('the removal needs a record type and field names');
  }
  const result = await context.tx.execute(
    sql`SELECT core.erase_personal_values(${erasure.recordType}, ${erasure.recordId}::uuid, ${JSON.stringify(erasure.fields)}::jsonb) AS changed`,
  );
  const changed = Number(result.rows[0]?.changed ?? 0);
  await writeSecurity({
    event: 'data_erased',
    recordType: erasure.recordType,
    recordId: erasure.recordId,
    details: { entries: changed, fields: erasure.fields },
  });
  return changed;
}
   ```
