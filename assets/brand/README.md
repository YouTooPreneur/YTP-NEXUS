## Themes

Nexus uses **one "mixed" style** (D-134, D-137) in **two colours**: **Emerald** (default: a dark-green menu, light ivory work area, dark-green text) and **Navy** (a navy menu, cool off-white work area, navy text). Both use the **neon-green logo** in the menu. Each person picks their colour. Neon green is an accent only (main buttons, active item, small highlights). The full colour system is written in step 1.6, Design.
